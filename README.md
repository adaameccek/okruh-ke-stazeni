# Okruh

Okruh na mapě: zadáš kilometry nebo minuty a ukáže, kam se dostaneš vzdušnou čarou, autem, na kole i pěšky.

**Vyzkoušet na webu:** https://okruh.adamhorak.cz

## Stažení pro Android

Nejnovější verze je v sekci [Releases](https://github.com/adaameccek/okruh-ke-stazeni/releases/latest) jako soubor `okruh.apk`. Stáhni ho v telefonu, otevři a povol instalaci z tohoto zdroje.

## Kód

Zdrojový kód je tu k nahlédnutí a ke stažení. Úpravy dělá jen autor, navržené změny (pull requesty) se nepřijímají.
